# Макеты кастомного сайта Betaline AI

Референс: [qwerty.digital](https://qwerty.digital/) — AI-интегратор полного цикла.
Позиционирование и уровень цен взяты по референсу (бесплатный вводный аудит,
консалтинг от 150 000 ₽, пилоты от 600 000 ₽ до 1 000 000 ₽).

Три независимых варианта дизайна. Каждый — самодостаточный `index.html`
(инлайн-стили, локальные шрифты, сгенерированная графика), открывается офлайн
двойным кликом.

| Вариант | Папка | Направление |
|---|---|---|
| **A «Чертёж»** | `a-chertezh/` | Светлый швейцарско-инженерный минимализм — ближе всего к референсу. Golos Text + IBM Plex Mono, кобальтовый акцент, графика-«чертежи». |
| **B «Сигнал»** | `b-signal/` | Тёмная «операторская»: телеметрия, приборные панели, мятное свечение. Tektur + JetBrains Mono. |
| **C «Кабинет»** | `c-kabinet/` | Премиум «частный банк»: чернильно-синий + золото, антиква Cormorant Garamond + Onest. |

## Структура каждого макета (по референсу)

Hero со статистикой → 5 услуг → 3 кейса → «Почему мы» → технологии →
процесс (4 этапа) → цены → CTA-форма аудита → футер.

## Общие ресурсы

- `assets/fonts/` — локальные шрифты (кириллица) + `fonts.css`
- `design/CONTENT.md` — контент-бриф (тексты, цены, структура)
- `design/philosophy-*.md` — дизайн-философии вариантов
- `design/shot.py` — скрипт полностраничных скриншотов (Playwright)

Контент единый во всех вариантах — сравнивается именно дизайн.
