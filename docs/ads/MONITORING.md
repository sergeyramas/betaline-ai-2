## Ритм

- **Ежедневно (5 мин), первая неделя:** таблица Кампании в Директе + Метрика «Источники, сводка» →
  «Переходы по рекламе». Пока нет боевого API-скрипта — по команде «глянь Директ» это делает агент
  через браузер (Haiku-сабагент, вывод — 6 цифр из таблицы выше).
- **Еженедельно:** сверка кликов↔визитов, отказов, CPA по целям; решение по стратегии.
- **Автоматика** появится вместе с боевым API Директа (отдельный чат): скрипт снимает Reports API +
  Метрика API раз в сутки, шлёт сводку и тревоги в Telegram оператору через `agent-fleet/tools/tg-send`.

## Варианты оптимизации — решает оператор

1. **Ничего не трогать 5–7 дней** — дать алгоритму Мастера обучиться; риск: ≈ 5 000 ₽ на мусор.
2. **Убрать РСЯ / мобильные приложения** — в Мастере кампаний площадки не выбираются напрямую;
   путь: «Перейти в режим эксперта» → ЕПК с местами показа «Только поиск», либо запрет показов
   на площадках in-app. Плюс: клики дороже, но целевые. Минус: потеря охвата РСЯ.
3. **Сузить гео до Москва + СПб** (как в остановленных кампаниях 707372684 и др.) и поднять
   недельный бюджет на поиск.

Что уже сделано без вопросов к оператору: ничего в стратегии не менялось после запуска.
