Показов нет с июля при статусе «Активна»: оплата за конверсии + смена сайта/целей летом (v3 → новые id событий) → алгоритму нечего оптимизировать, аукцион перестал давать показы. Автоприменение рекомендаций при этом включено — при возобновлении Директ может сам сменить цели/бюджет.
