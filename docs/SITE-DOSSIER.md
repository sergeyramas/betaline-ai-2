## 2. Что такое v3

Одностраничник «продукт-герой»: статичный HTML/CSS/vanilla JS + serverless-функции
на Vercel (Node 22, CommonJS). Без фреймворков и внешних CDN — шрифты Inter
самохостятся. Исключения по внешним скриптам: Яндекс.Метрика и CallbackFire.

Логика построения (из исследования landing-v2→v3): pain-driven вход через «затыки»,
живая диагностика в Telegram-агенте, кейсы «цифры вперёд» с легендой,
анти-конструкторное позиционирование.

## 6. Gap-анализы и аудит

### 6.1 Аудит v3 по трём осям (2026-08-26)

Полный отчёт: [`docs/agents/reports/2026-08-26-utp-and-audit.md`](agents/reports/2026-08-26-utp-and-audit.md)

| Ось | Вердикт |
|---|---|
| Стилистика боевого betaline-ai.ru | ✅ наследует почти 1:1 |
| Gap-анализ исследования (рекомендации ревьюеров) | ✅ ~82% покрытия: 11/14 полностью, 4 частично |
| Минимализм «по книге» (протокол владельца) | ❌ 0/12 полностью |

**Закрыто полностью (11):** строка-УТП в hero; блок затыков «боль→действие→цифра»;
3+2 карточки с «показать ещё»; полоса интеграций; диагностика→@BetalineAI_bot;
hero-мокап с действием в CRM; кейсы «цифры вперёд» с легендой; анти-конструкторное
позиционирование в FAQ №1; именованный инженер с фото; порядок блоков по wireframe;
CTA «разберите процесс» вместо «оставьте заявку».

**Закрыто частично (4):** wildcard-карточка «ваш затык другой» спрятана под
«показать ещё» (советовали заметнее); слово «ситуация» вместо «затык» — только в бейдже;
позитивная карточка-исход — только метриками; процессный таймлайн без схемы-пайплайна.

**Вне периметра (1):** «3 кнопки + свободный текст + честное обещание» — логика
самого Telegram-агента, на сайте не проверяется.

**Конфликт осей:** «бренд боевого» и «минимализм по книге» взаимоисключающи.
v3 сознательно выбрал бренд. Смена оси = перестройка шрифта, палитры, радиусов и
теней целиком. Развилка — за оператором.

**Быстрые улучшения без смены оси:** убрать эмодзи из квиза и success-сообщений
(заменить на SVG); wildcard-карточку поднять к первым трём; дожать «ситуация»
вместо «затык» в заголовке.
